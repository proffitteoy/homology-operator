# 联合输出契约（设计稿）

本契约延续 [D1、T2、T3 与第3节](https://github.com/proffitteoy/homology-operator-lab/blob/6143729669902ee875b211b58085e954c76cdf88/docs/proof/PROOF.md)。下述名称描述逻辑操作，尚不是已实现API。

## 输入

1. 有限过滤的有序尺度与明确的末端延拓约定
2. 每个尺度/次数的带基 F₂ 链空间、相邻边界矩阵；验证边界复合为零
3. 跨尺度链映射及其链映射/复合相容性；第一版优先过滤包含映射
4. 正坐标权重及其语义（长度、面积、体积或人为代价），记录跨尺度权重是否继承
5. 求解策略、资源上限、可复现并列选择约定

不要求调用者先提供 PH、同调基或最短类表。内部消元/循环空间计算必须计入成本。

## 一个结果对象的两种读取

每个阶段/次数保留同一个投影 P、L=I+P 或其可验证的矩阵自由表示，并绑定源边界矩阵、坐标顺序与权重标识。

拓扑读取：核与原同调的显式对应、目标投影后的包含传输、各区间传输秩和由秩恢复的条形码。逐尺度 Betti 数不能代替完整 PH。

几何读取：对循环 z 输出 Pz；质量为其原坐标权重之和。对两个循环 z,y，距离为质量(P(z+y))；零距离当且仅当两输入同调。对两个选定输出，共享支撑直接从共同坐标计算，并与质量恒等式核对。非循环输入必须拒绝或明确标为回缩模式，不能套用循环上的保证。

PH 和几何读取引用同一投影身份，不得分别运行两个不相容求解器后拼接结果。真实最短类质量是可选优化输出；选定代表质量不能改名为最短质量。

## 认证等级与缺失状态

- 同调正确的可行投影与全局最小伸长投影分开标识
- 精确有理证书、数值上下界与启发式结果分开
- 返回不可行输入、未计算、资源耗尽、无类、有效零值的不同状态
- 完整核向量/全类表有指数规模，默认提供按需查询；不可承诺全表免费
- 基变换不改 PH，但几何依赖原链基、权重和投影选择，必须保留这些元数据

资源不足不能静默退化为近似 PH。尚未实现的求解后端应明确返回 unavailable。
